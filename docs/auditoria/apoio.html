Canal Studio: YouTube API compliance summary

Google Cloud project ID project-7c0dd44f-35ae-4636-9fa · Contact: gabribragandrade@gmail.com · October 2026

1. What the app is

Canal Studio is a private Windows desktop app. Its only user is the developer, who uses it to produce documentary videos for their own YouTube channels. It has no public sign-up, no accounts and no backend server. Website, privacy policy and terms: gabriell-braga.github.io/-canal-studio.

2. OAuth scopes and why each one is needed

ScopeUsed for
youtube.uploadUpload the videos the owner approved (videos.insert).
youtube.force-sslSet the custom thumbnail (thumbnails.set) and upload English subtitles (captions.insert).
youtube.readonlyRead the owner's channel name and picture (channels.list).
yt-analytics.readonlyShow views, watch time, average view duration and subscribers gained of the owner's own videos (reports.query).

4. Human oversight

  • The owner reviews, edits and approves every script, with AI fact-check warnings shown next to it.
  • The owner watches and approves every finished video, its title, description, thumbnail and publish time.
  • Nothing is uploaded without both approvals. Uploads are scheduled, and the owner can still edit or cancel them in YouTube Studio.
  • Every upload sets the altered or synthetic content disclosure, because narration and some images are AI-generated.
  • Stock media comes from Pixabay, Pexels and Wikimedia Commons under licenses that allow this use. Authors are credited in the description when the license requires it.

5. Data handling

  • Storage: OAuth tokens are encrypted with Windows DPAPI (Electron safeStorage) and kept in a local SQLite database on the owner's PC. Cached channel statistics stay in the same database.
  • Sharing: YouTube and Google data goes only between the PC and Google's APIs. It is never sent to another service, sold, used for advertising or used to train AI models.
  • Other services: the Claude API (optional) receives only the topic and the script text. Stock media sites receive only search keywords.
  • Display: the app shows statistics only for the owner's own channels, only to the owner.
  • Refresh and retention: cached statistics are refreshed from the API when the owner opens the statistics screen, and each record keeps the time of its last update. Deleting the app data folder removes them.
  • Revocation: Disconnect in the app deletes the stored tokens. Access can also be revoked at myaccount.google.com/permissions.
