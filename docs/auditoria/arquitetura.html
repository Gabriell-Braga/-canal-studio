Canal Studio: architecture

Private Windows desktop app. One user (the channel owner). No backend server.
Channel owner's Windows PC (everything below runs locally)
Canal Studio (Electron app)
User interface (React) Script review and approval, final video approval, upload queue, channel statistics, Connect / Disconnect YouTube
Main process (Node.js) Production pipeline and job queue OAuth 2.0 with loopback redirect (127.0.0.1) YouTube client (googleapis) Uploads only videos the owner approved Sets the altered or synthetic content disclosure on every upload
Local database (SQLite) Scripts, videos, upload status, cached statistics of the owner's channel
Windows DPAPI (safeStorage) Encrypts the OAuth tokens before they are stored. Deleted on Disconnect.
Local AI and render services (same PC)
Python server (127.0.0.1:8765) Kokoro TTS: narration faster-whisper: timed subtitles Image cutout for thumbnails
ComfyUI (127.0.0.1:8188) Stable Diffusion XL: illustrations for scenes and thumbnails
Ollama (optional) Local language model for script drafts
Remotion + ffmpeg Render the final video, the Shorts and the thumbnail on the PC. The output files stay on the PC until the owner approves the upload.
Google (HTTPS)
Google OAuth 2.0 Consent screen and tokens. Scopes: youtube.upload, youtube.force-ssl, youtube.readonly, yt-analytics.readonly
YouTube Data API v3 videos.insert (private, status.publishAt, containsSyntheticMedia) thumbnails.set, captions.insert, channels.list
YouTube Analytics API reports.query: views, watch time and subscribers of the owner's own videos
Other services (receive no YouTube data)
Anthropic Claude API (optional) Receives only the video topic and the script text, to draft and fact-check scripts
Pixabay, Pexels, Wikimedia Commons Receive only search keywords. Return licensed stock footage and images. Authors are credited when the license requires it.
IPC
local HTTP / processes
HTTPS, Google data only
HTTPS: topic + script text, search keywords
Solid arrows carry Google or YouTube data and go only to Google. Dashed arrows carry no YouTube data. Tokens are encrypted with DPAPI and can be revoked in the app (Disconnect) or at myaccount.google.com/permissions.
