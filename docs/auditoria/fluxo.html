Canal Studio: user flow

One user: the channel owner. Nothing reaches YouTube without two human approvals.
Automatic step or owner action Human approval gate (reject sends the item back for edits) Google / YouTube API call
1
Connect YouTube
The owner clicks Connect YouTube. The browser opens Google's consent screen; the owner picks the channel account and grants the scopes. The app receives the code on 127.0.0.1 and stores the tokens encrypted with DPAPI.
Google OAuth 2.0 · channels.list (channel name and picture)
2
Choose a topic
The owner adds or picks a documentary topic for one of the connected channels.
No YouTube API call
3
AI drafts and fact-checks the script
A language model (Claude API or local Ollama) drafts the narration and flags claims that need checking.
No YouTube API call (only topic and script text are sent)
4
Owner reviews and approves the script
The owner reads the script and the fact-check warnings, edits it and approves it. A rejected script goes back to step 3.
No YouTube API call
5
Local production
On the owner's PC: narration (TTS), subtitles, licensed stock footage and AI images, video render, Shorts, thumbnail, title and description.
No YouTube API call
6
Owner approves the final video
The owner watches the video, checks title, description, thumbnail and publish time, and approves it. The altered or synthetic content disclosure is always on.
No YouTube API call
7
Scheduled upload
The upload queue sends the approved video as private with the chosen publish time, then sets the thumbnail and uploads the English subtitles.
videos.insert · thumbnails.set · captions.insert
8
YouTube publishes the video
At the scheduled time YouTube makes the video public (status.publishAt). The owner can still edit or cancel it in YouTube Studio.
Done by YouTube, no call from the app
9
Owner views channel statistics
The YouTube screen shows views, watch time, average view duration and subscribers gained for the owner's own videos.
reports.query (YouTube Analytics API)
10
Disconnect at any time
Disconnect deletes the stored tokens from the PC. Access can also be revoked at myaccount.google.com/permissions.
No YouTube API call
